# 06 AI Governance

Structured loosely on the NIST AI Risk Management Framework functions: Govern, Map, Measure, Manage.

## 1. Govern: model and prompt inventory

Nothing goes into use without a row here.

| ID | Component | Model / version | Purpose | Owner | Eval gate | Status |
|----|-----------|-----------------|---------|-------|-----------|--------|
| M-01 | Embeddings | Databricks-hosted `databricks-gte-large-en` (1024 dims), ADR-010 | Chunk and query vectors | AI Model Owner | Retrieval recall at 5 of at least 0.80 on gold set | In use (dev) |
| M-02 | Entity extraction | Via the LLM gateway (ADR-011), prompt `extract-v1` | Build graph from chunks | AI Model Owner | Schema validity 100 percent (DQ-G-003, DQ-G-005), spot check precision of at least 0.85 on 50 chunks | Planned |
| M-03 | Answer generation | Gateway route: Databricks-hosted `databricks-meta-llama-3-3-70b-instruct`, fallback `databricks-gpt-oss-120b`, prompt `answer-v1` | Answer user questions with citations | AI Model Owner | Judge score average of at least 4.0 and citation rate 100 percent | Building |
| M-04 | Judge | Gateway, public data only, so Gemini `gemini-2.5-flash` is allowed as a second opinion; prompt `judge-v1` | Score answers | Evaluator | Agreement with human labels of at least 0.75 (within 1 point) | Planned |

Every chat model call goes through the LLM gateway (ADR-011): the data's classification decides which models may receive it, user questions go only to Databricks-hosted models, and every call is logged to `gold.llm_call_log` without prompt or answer text. External models (Gemini today, a frontier model through an enterprise channel in production) are used only for data they are allowed to see.

## 2. Map: intended use and limits

**Intended use:** Help someone find and understand which Ontario retirement home and long-term care regulations apply to a situation, with links to the exact sections.

**Not intended for:**

- Legal advice. Every answer carries a line saying it is not legal advice and the linked section is the authority.
- Decisions about individual residents.
- Any use with personal or health information.

**Known limits:**

- Regulations change. The platform is only as current as the last bronze load date, which the app shows.
- LLM extraction misses or mislabels some relationships. Graph answers can be incomplete.
- Scanned PDFs without OCR produce no text (caught by DQ-S-001).

## 3. Measure: evaluation

| What | How | Where stored |
|------|-----|--------------|
| Retrieval quality | Recall at k against `expected_sources` in the gold set | `gold.eval_results` |
| Answer quality | LLM judge, 1 to 5 on a written rubric | `gold.eval_results.judge_score` |
| Judge trustworthiness | Human labels on a sample, agreement rate | `gold.eval_results.human_label` |
| Faithfulness | Judge checks every claim is backed by a retrieved chunk | `gold.eval_results` |
| Refusal | Gold set includes questions with no answer in the sources; the app must say it does not know | category `negative` |
| Cost and latency | From the gateway | `gold.llm_call_log` |

The gold set is written by hand, versioned, and never generated by the same model it evaluates.

## 4. Manage: release gates and monitoring

A new model or prompt version can only go live if:

1. Its eval gate in the inventory above passes on the current gold set
2. Its scores are not worse than the current live version by more than 0.2 on average
3. The change is in a PR with the eval results attached

Prompts are files in `config/prompts/` with a version in the file name. Changing a prompt means a new version, never an edit in place. Rollback means pointing config back to the previous version.

## 5. Answer policy

The app must:

- Cite at least one source for every answer
- Say "I could not find this in the loaded regulations" when retrieval returns nothing relevant, not guess
- Show the load date of the data it used
- Show the not-legal-advice line

## 6. Incident types

| Type | Example | Response |
|------|---------|----------|
| Wrong answer with confident citation | Cites a section that says something else | Add to gold set as a new question, investigate chunk and prompt |
| PII in an answer | A name from an inspection report shows up | Treat as incident: see [runbooks/pii_found.md](runbooks/pii_found.md) |
| Cost spike | Retry loop burns tokens | Gateway hard limit stops it; see [10](10_cost_management.md) |
